# Kos Uni Salma - Landing Page & Web Portal

Landing page modern, responsif, dan elegan untuk **Kos Uni Salma**, hunian kos eksklusif dengan fasilitas lengkap, aman, dan asri. Dibangun dengan **Next.js 16 (App Router)**, **React 19**, **TypeScript**, dan **Vanilla CSS** untuk performa tinggi, kecepatan muat instan, dan estetika premium.

---

## Fitur Utama

- **Lokasi Spesifik**: Beralamat di `75JC+5QQ, Gg. Puyuh, Air Jamban, Kec. Mandau, Kabupaten Bengkalis, Riau 28784`, dekat pusat kota Duri, Simpang Pokok Jengkol, dan pusat kebutuhan harian.
- **2 Pilihan Tipe Kamar**:
  1. **Tipe Kamar AC**: Udara dingin sejuk terawat, kamar mandi dalam, tempat tidur, lemari, meja & kursi.
  2. **Tipe Kamar Kipas Angin**: Hemat dan adem, sirkulasi udara alami, kamar mandi dalam, tempat tidur, lemari, meja & kursi.
- **Fasilitas Kamar (Semua Kamar)**: Kamar mandi dalam pribadi (100% kamar), kasur/tempat tidur, lemari pakaian, serta meja dan kursi belajar/kerja.
- **Fasilitas Bersama & Eksterior**:
  - **Dapur Bersama Lengkap**: Kompor, kulkas, peralatan masak, dan dispenser air minum.
  - **Garasi Luas & Parkiran Luas**: Daya tampung lega berkanopi untuk mobil dan motor dengan pagar aman tertutup.
- **Kalkulator Biaya Sewa Dinamis**: Simulasi biaya sewa berdasarkan durasi (1, 3, 6, 12 bulan) dengan perhitungan diskon otomatis hingga 15% dan integrasi link pesan WhatsApp instan.
- **Galeri Foto Interaktif**: Grid galeri suasana kos asli (gedung utama, kamar AC, kamar kipas angin, kamar mandi dalam, dapur bersama, garasi/parkir).
- **Aksesibilitas & Lokasi**: Informasi jarak dan waktu tempuh di kawasan Air Jamban / Mandau / Duri, lengkap dengan navigasi Google Maps (Plus Code 75JC+5QQ).
- **Formulir Survey & Reservasi**: Formulir pendaftaran jadwal survey yang langsung memformat pesan rapi ke WhatsApp Uni Salma.
- **FAQ Accordion**: Tanya jawab interaktif seputar jam malam (akses 24 jam dengan smart card), aturan listrik token, fasilitas, dan ketentuan berkunjung.
- **Floating WhatsApp CTA**: Tombol aksi mengambang yang responsif dan selalu siap membantu pengunjung.

---

## Teknologi yang Digunakan

- **Framework**: Next.js 16.4.3 (App Router, Turbopack, React Server Components)
- **Library**: React 19.3.0
- **Bahasa**: TypeScript 5
- **Styling**: Vanilla CSS (Custom CSS Design System, tokens, glassmorphism, responsive breakpoints)
- **Icons**: Lucide React
- **Typography**: Google Fonts (Plus Jakarta Sans)

---

## Cara Menjalankan Project

### 1. Jalankan Development Server
```bash
npm run dev
```
Buka browser dan akses [http://localhost:3000](http://localhost:3000).

### 2. Membangun Versi Produksi (Production Build)
```bash
npm run build
npm run start
```
